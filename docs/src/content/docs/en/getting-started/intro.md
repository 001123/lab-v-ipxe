**iPXE ZTP** is an all-in-one Zero Touch Provisioning server packaged as a **single lightweight binary**. It unites an automated iPXE HTTP bootloader, Ubuntu autoinstall cloud-init configuration generator, machine inventory backed by SQLite, and a modern admin web console.

```
Machine powers on → router (OpenWrt dnsmasq, iPXE via TFTP) → chain http://<app>/boot.ipxe?mac=${net0/mac}
  ├─ unknown MAC   → create a "pending" machine + waiting script (re-polls every 10s)
  ├─ pending       → waits for administrator approval in the UI
  ├─ approved      → switches to "installing", serves boot script (NFS) + autoinstall user-data
  │                  (missing kernel/initrd → downloads ISO, caches ~100MB, deletes ISO)
  ├─ install done  → late-command phone-home POST /api/machines/installed → "installed"
  │                  (or manual "Mark installed" in UI)
  └─ installed     → sanboot from local disk (prevents reboot installation loops)
```

## Architectural Design

The project is built on the philosophy of simplicity, performance, and zero runtime dependencies:

### 1. Backend (`v.mod`, `main.v`)
- Written in **V (0.5.2)** with the bundled **veb** web framework.
- Compiles directly to a native C binary without any interpreter overhead.
- Includes embedded SQLite 3 database (`WAL` mode) with automatic migration.
- Serves dynamic iPXE scripts (`/boot.ipxe`), cloud-init autoinstall user-data (`/autoinstall/:mac/user-data`), and REST APIs under `/api/*`.

### 2. Frontend (`web/`)
- Built with **Next.js 16** (App Router, statically exported with `output: 'export'`).
- React 19 + TypeScript + Tailwind CSS v4 + **shadcn/ui** (Base UI).
- Real-time polling and optimistic updates via **SWR**.
- The entire build output (`web/out`) is embedded directly into the V binary at compile time via `$embed_file` (generated by `scripts/gen_embed.vsh`).

### 3. Provisioning Engine
- **Target OS**: Ubuntu Server 24.04.5 LTS & 26.04.1 (pinned exact releases).
- **Boot Protocol**: NFS boot for maximum local network throughput.
- **Smart ISO Cache**: Automatically fetches official Ubuntu ISOs on demand, extracts only the ~100MB `vmlinuz` and `initrd`, caches them, and deletes the multi-gigabyte ISO.
- **Disk Partitions**: Selectable presets: `direct` (ext4), `zfs` root with custom ARC memory tuning, or `lvm`.
